# Songs

Put mp3, m4a, wav or ogg files here, then commit and push. The site plays them as the SONG tape.

- The title comes from the file name: `Soundtrack - Le Perv.mp3` shows as "Le Perv".
- Files are used as-is. For even volume, use the loudness-matched copies from `app/audio/songs/` (made by `node tools/build-audio.js`).
- Everything here is public: anyone with the site link can download it.
